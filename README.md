# Carcassonne board generator

This project is meant to find answers to the following questions:

- How do the biggest cities that you can build in Carcassonne look like?
- Which maps can you build with geometric constraints on the map shape (e.g. a perfect square with no holes)?
- How do the longest possible roads look like?

And more!

# Project structure

The Carcassonne boards are computed using Answer Set Programming (clingo) and visualized with `viz.py`.
